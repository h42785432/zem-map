# 大阪工業大学周辺　迂回ルートマップ
大阪工業大学枚方キャンパス周辺を4地域に分け、
通常時の最短経路と、大通りの一部が通行止めになった場合の
迂回経路を比較する展示用シミュレーションです。

## 主な機能
・4地域から出発地を選択
・通常時の最短経路を表示
・大通り通行止め時の迂回路を表示
・距離、推定時間、増加距離を比較

## 使用技術
・Python
・Streamlit
・OSMnx
・folium
・OpenStreetMap
